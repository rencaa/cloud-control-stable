# 云控脚本

## 直接进入指定抖音直播间

脚本文件：

`enter_douyin_live_room.js`

这个任务脚本不需要修改手机端 `douyin.js`，直接使用现有任务执行环境中的
`utils.openActivity` 调用抖音跳转意图。

然后在云控网页中：

1. 打开「脚本管理」，新建脚本。
2. 脚本名称填写：`抖音-直接进入指定直播间`。
3. 把 `enter_douyin_live_room.js` 的内容复制到脚本内容。
4. 打开「任务管理」，创建任务并关联这个脚本。
5. 选择目标设备。
6. 任务参数填写：

```json
{
  "live_room_id": "1234567890123456789"
}
```

`live_room_id` 也可以填写包含 `room_id` 的抖音链接。手机端使用的直达意图是：

```text
snssdk1128://live?room_id=直播间ID
```

这个任务不走关键词搜索、不点击直播标签，也不修改手机业务脚本，只调用抖音
Deep Link 直接跳转。
