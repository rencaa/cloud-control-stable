# 国内 Ubuntu 24.04 服务器一键安装

这套方式专门针对中国大陆网络和 2 核 / 2 GiB / 16 GiB 小主机：

- 不安装 Docker，不访问 Docker Hub。
- 不在服务器下载 Go 工具链，也不在服务器编译。
- 安装包自带 amd64、arm64 两个预编译成品并自动识别架构。
- APT 默认临时使用阿里云 Ubuntu 24.04 镜像，失败自动回退服务器原软件源。
- 不永久改写服务器的 Ubuntu 软件源。
- 只从 APT 安装 Nginx、Certbot 和少量系统组件。
- 后端只监听 `127.0.0.1:18081`，内置明文 MQTT 默认关闭，公网设备使用 WSS。
- 使用 systemd 自动启动、故障重启并限制为最高 512 MiB 内存。
- 手机免令牌模式在服务端按 IP 防重连风暴，不增加手机配置项。
- 80% 磁盘告警、90% 写入保护、每分钟自愈检查和 20 MiB 日志轮转。

## 1. 在 Windows 生成国内极速包

```powershell
cd C:\Users\Administrator\Desktop\yun\cloud-control-stable
powershell -ExecutionPolicy Bypass -File deploy\package-cn.ps1
```

生成文件：

```text
C:\Users\Administrator\Desktop\yun\cloud-control-stable\release\cloud-control-stable-cn-fast.tar.gz
```

上传：

```powershell
scp release\cloud-control-stable-cn-fast.tar.gz ubuntu@服务器IP:/tmp/
```

## 2. 连接服务器后直接运行

局域网免令牌一键下载、校验并安装：

```bash
cd /tmp && curl -fL --retry 5 -O https://work.kd99.cn/https://github.com/rencaa/cloud-control-stable/releases/latest/download/cloud-control-stable-cn-fast.tar.gz -O https://work.kd99.cn/https://github.com/rencaa/cloud-control-stable/releases/latest/download/cloud-control-stable-cn-fast.tar.gz.sha256 && sha256sum -c cloud-control-stable-cn-fast.tar.gz.sha256 && tar -xzf cloud-control-stable-cn-fast.tar.gz && sudo bash cloud-control-cn/install-cn.sh --lan
```

域名必须已经解析到服务器，安全组开放 TCP 80、443。连接服务器：

```powershell
ssh ubuntu@服务器IP
```

登录以后复制执行这一条命令：

```bash
cd /tmp && tar -xzf cloud-control-stable-cn-fast.tar.gz && sudo bash cloud-control-cn/install-cn.sh --domain control.example.com --email admin@example.com
```

把域名和邮箱换成自己的。脚本会自动完成系统检查、安装国内加速依赖、swap、用户、目录、systemd、Nginx、HTTPS、证书续期、启动和健康检查。

局域网手机免令牌接入使用独立端口，不会停止旧服务：

```bash
cd /tmp && tar -xzf cloud-control-stable-cn-fast.tar.gz && sudo bash cloud-control-cn/install-cn.sh --lan
```

访问地址为 `http://服务器局域网IP:18080`。手机端只填写局域网 IP，自动使用 WS、18080 端口和本机生成的设备 ID，不需要设备令牌。此模式只允许 `10.x`、`172.16-31.x` 或 `192.168.x` 地址，禁止把 18080 映射到公网。

## 3. 安装结果

安装目录：

```text
/opt/cloud-control-native
```

管理员密码会显示在终端，并保存到：

```text
/opt/cloud-control-native/install-credentials.txt
```

查看密码：

```bash
sudo cat /opt/cloud-control-native/install-credentials.txt
```

查看状态和日志：

```bash
sudo systemctl status cloud-control-native --no-pager
sudo tail -f /var/log/cloud-control-native/server.log
curl -fsS http://127.0.0.1:18081/readyz
systemctl list-timers 'cloud-control-native-*'
```

数据目录：

```text
/opt/cloud-control-native/data
/opt/cloud-control-native/backups
/opt/cloud-control-native/uploads
```

脚本启动时立即创建 SQLite 一致性备份，之后每天备份并保留 7 份。

磁盘达到 80% 时监控日志会告警；预计资源上传、截图或备份会使磁盘达到 90% 时，服务会拒绝该次大文件写入，但设备心跳和控制连接继续工作。

### 可选：同步到 USB、NAS 或另一台局域网主机

本地挂载目录：

```bash
sudo bash cloud-control-cn/install-cn.sh --lan --backup-target /mnt/cloud-backup
```

SSH 主机：

```bash
sudo bash cloud-control-cn/install-cn.sh --lan \
  --backup-target backup@192.168.1.20:/srv/cloud-backup \
  --backup-key /root/.ssh/id_ed25519
```

同步任务每天约 03:30 执行，并带随机延迟。可用 `sudo systemctl start cloud-control-native-backup-sync.service` 手动验证一次。

## 4. 设备注册

`--lan` 模式不需要注册或令牌，手机首次连接并发送基础信息后会自动出现在设备列表。

以下流程仅适用于正式 HTTPS 令牌模式。

首次只注册指定测试设备时，可以在正式 HTTPS 安装命令末尾增加：

```text
--enable-registration
```

注册完成后编辑：

```bash
sudo nano /opt/cloud-control-native/.env
```

恢复：

```dotenv
CLOUD_DEVICE_AUTO_REGISTER=false
```

然后执行：

```bash
sudo systemctl restart cloud-control-native
```

## 5. 回滚

回滚到安装器保留的上一软件版本：

```bash
sudo cloud-control-native-rollback
```

回滚前的当前程序、配置和 unit 会再次保存到 `/opt/cloud-control-native/backups/software-rollback-时间/`。该操作只回滚程序和配置，不回退或删除 SQLite 数据。

只停止国内原生版、不删除任何数据：

```bash
sudo systemctl disable --now cloud-control-native
```

如果安装前存在原服务，它没有被安装脚本停止。原生版使用独立的 `/opt/cloud-control-native`、独立 systemd 服务和独立 SQLite 数据。

如果升级后的二进制无法通过健康检查，安装器会自动恢复 `cloud-control-server.previous`、`.env.previous` 和上一个 systemd unit。

## 6. 国内网络说明

默认 `--mirror aliyun` 只为本次安装临时使用阿里云镜像，不修改 `/etc/apt/sources.list.d/ubuntu.sources`。amd64 使用 `ubuntu`，arm64 自动使用 `ubuntu-ports`。如果服务器本身已经配置腾讯云、阿里云或华为云内网源，可以改用：

```text
--mirror system
```

阿里云提供了 Ubuntu 24.04 的 x86 和 Ubuntu Ports 镜像配置说明：

- https://developer.aliyun.com/mirror/ubuntu
- https://developer.aliyun.com/mirror/ubuntu-ports
