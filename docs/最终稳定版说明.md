# 云控最终稳定版 v2026.08.24-final

该目录是从 cn3 稳定版复制出的独立最终版本，不覆盖旧目录、旧安装包或服务器上的现有数据。

## 主要稳定性改造

- WebSocket 单消息上限 8 MiB，完整截图上限 4 MiB。
- 数据库队列最多 1024 个任务、64 MiB；媒体队列最多 32 个任务、24 MiB。
- 短信和联系人每次最多处理 200 条，先截断和压缩，再批量写入；联系人按最新快照替换。
- 屏幕墙最多同时预览 16 台，前端 4 秒轮询，页面隐藏时暂停；接口支持 `since` 增量参数并限制单次响应大小。
- 任务设备分批创建、每批 250 台后台派发；低配默认单任务最多 2000 台，可通过 `CLOUD_TASK_MAX_DEVICES` 调整，硬上限 10000。
- 停机时依次停止新请求、定时任务、设备输入、数据库/媒体/审计队列，最后执行 WAL checkpoint 并关闭数据库。
- 自动清理设备日志、指标、投递记录、任务日志、系统日志和短信。
- SQLite 启动执行 `quick_check`，定期被动 checkpoint；每份备份执行完整性检查并生成 SHA256。
- 安装器保存程序、环境变量、systemd、Nginx、凭据、监控、备份同步与日志轮转配置的一代完整回滚快照。
- 备份同步后校验 SHA256，每周用 SQLite 只读打开备份并执行 `integrity_check`。

## 局域网一键安装

```bash
cd /tmp && curl -fL --retry 5 -O https://work.kd99.cn/https://github.com/rencaa/cloud-control-stable/releases/latest/download/cloud-control-stable-cn-fast.tar.gz -O https://work.kd99.cn/https://github.com/rencaa/cloud-control-stable/releases/latest/download/cloud-control-stable-cn-fast.tar.gz.sha256 && sha256sum -c cloud-control-stable-cn-fast.tar.gz.sha256 && tar -xzf cloud-control-stable-cn-fast.tar.gz && sudo bash cloud-control-cn/install-cn.sh --lan
```

安装完成后读取：

```bash
sudo cat /opt/cloud-control-native/install-credentials.txt
```

回滚上一软件版本（不会回滚数据库）：

```bash
sudo cloud-control-native-rollback
```

查看备份验证状态：

```bash
sudo systemctl status cloud-control-native-backup-verify.timer --no-pager
sudo journalctl -u cloud-control-native-backup-verify.service -n 50 --no-pager
```
